# Oxide Arcade

The **Oxide Arcade Project** has the goal to display three games, in increasing coding difficulty, coded in Rust and using Bevy.
This repo is not just the display of the learning project, but also a documentation of the complete roadmap.
This documentation can be found within the `design-doc/` folder.

## Games

The three games that define the goal of `oxide-arcade` are (in ascending difficulty order):

1. [**Pong**](https://es.wikipedia.org/wiki/Pong) - WIP
2. [**Snake**](https://en.wikipedia.org/wiki/Snake_(video_game_genre)) - WIP
3. [**Tetris**](https://en.wikipedia.org/wiki/Tetris_(NES_video_game)) - WIP
